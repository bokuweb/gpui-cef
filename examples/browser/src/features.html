gpui-cef feature test page

Each button exercises one thing a windowless browser cannot do on its own. What the page saw is listed at the bottom; what the application saw is in the side panel.

Popups

target=_blank rel=noopener
Blocked by default and reported as PopupRequested; the demo opens the URL in the system browser.

Navigation filter

Go to blocked.example
The demo's filter turns down blocked.example, so the page stays here and NavigationBlocked is reported.

JavaScript dialogs

Answered with native gpui prompts. Tick the box, then reload or navigate to see the "leave this page?" dialog.

File chooser

Downloads

Download a data: URL Download to decline
The demo asks where to save with a native save panel; cancelling it cancels the download.

Renderer crash and load errors

After a crash the demo shows a banner with Reload. A failed load is reported as LoadFailed.

Printing

window.print() opens the system print panel as a window of its own, not attached to the app's window, and the page waits until it is closed. Printing to PDF is the path the application controls.
